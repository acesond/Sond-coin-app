# 손디코인분석 웹앱

손디코인분석 — 매억남·박경철 실전 1장 기준으로 BTC·ETH·SOL·XRP·BNB·DOGE 무기한 선물을 분석하는 모바일 웹앱입니다.
멀티 타임프레임 RSI·거래량·다이버전스 자동 판정, 가설 타점, 손익비 계산기, 매매 전 체크리스트를 제공합니다.
시세는 바이낸스 USDT-M 선물 공개 API(`https://fapi.binance.com`)에서 브라우저가 직접 받아옵니다.

## 사용

- 웹: https://acesond.github.io/Sond-coin-app/
- 모바일 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 전체 화면으로 실행됩니다.

## 구성

- `index.html` — 단일 파일 앱 (외부 빌드·서버 불필요)
- `crypto-events.json` — 코인·거시 주요 일정 원본(시장 자극 요약 `stimulus_summary`, 자세히 보기 풀이 `detail`)
- `scripts/ntfy_alert.py` — 6종목 3중 점검을 파이썬으로 다시 계산해 3/3 타점 도달일 때만 ntfy 푸시를 보내는 감시 스크립트 (NEoWave·1D 역추세는 본문 참고 줄로만). 같은 스크립트가 웹앱 «자동 후보»의 **자동 1(4H 모노웨이브 추세 재개)** 근접도 함께 감시합니다.
- `.github/workflows/coin-alert.yml` — 15분마다 위 스크립트를 실행하는 GitHub Actions 워크플로 (`actions/cache`에 60분 쿨다운 상태 저장)
- `scripts/apps-script-sync.gs` — 구글 시트 동기화 서버 코드(Apps Script V8). v2부터 매매기록·자산과 **분리해 예약주문**도 저장합니다(`예약주문`·`_OrdersJSON` 탭). 시트 배포 방법은 파일 머리말 참고.
- `scripts/order_watch.py` — 시트의 **미체결 예약주문**만 읽어 관점 변경·무효화를 판정하는 CLI. 종료 코드로만 알리는 `check.sh`(피클 예약 작업)가 이 파일을 씁니다.
- `scripts/test-sync-harness.py` · `test-apps-script-orders.py` · `test-order-watch.py` — 동기화·시트·감시 테스트(모두 가짜 서버·가짜 시세).

## 매매기록 · 바이낸스 수수료

- `📒 매매기록`은 `전체 · 승 · 패 · 진행중 · 종료`로 결과만 골라 볼 수 있고, 요약(건수·승률·총 손익·평균 ROE)도 고른 조건 기준으로 다시 계산됩니다.
- `내 타점 · 손익비 계산기`와 청산 기록에 바이낸스 선물 VIP 0 왕복 수수료(**시장가 0.10% / 지정가 0.04%**)를 적용합니다. 수수료 = 증거금 × 레버리지 × 왕복 수수료율이고, 자산현황은 수수료를 뺀 **순손익**으로 계산합니다. 수수료 정보가 없는 예전 기록은 기존 금액을 그대로 두고, 카드의 `수정`으로 수수료율을 바꾸면 그 기록부터 다시 계산됩니다.

## 자동 알림 (ntfy)

- 토픽: `https://ntfy.sh/sond-coin-9842k` (ntfy 앱에서 이 토픽을 구독하면 폰으로 푸시가 옵니다)
- 알림 조건: ① 자리 · ② 라인 · ③ 다이버전스가 모두 충족된 **3/3 타점 도달**일 때만. 같은 종목·같은 방향은 60분 쿨다운. 매억남 기본 원칙이 메인 판정이라 NEoWave 파동 겹침·1D 역추세로 판정을 깎지 않고 참고 줄로만 남깁니다.
- **진입 구간 일치**: 근거 3/3이어도 현재가가 그 가설의 진입가 **±1.0%** 밖이면 `타점 도달`이 아니라 `3/3 대기 — 구간 밖(진입가 X% 차이)`으로 남습니다. 판정 방향도 현재가가 실제로 들어와 있는 가설을 먼저 봅니다(숏 구간 안에서 롱 판정이 뜨지 않음). 웹앱·ntfy 스크립트가 같은 기준입니다.
- 데이터: 바이낸스 선물(`fapi.binance.com`) 우선, HTTP 451 등으로 막히면 OKX 퍼블릭 API로 자동 폴백.
- **자동 1 알림** (2026-11-26 추가): 웹앱 «자동 후보 · 추세 재개»(4H ATR(14)×2.5 모노웨이브의 직전 파동 m1을 0.5 → 0.618 → 0.786 되돌림)에서 현재가가 진입가 **±0.8%** 안에 들어오면 제목 `[자동 1] BTC SHORT 타점 도달`로 별도 푸시. 파동 무효선(m1 시작점 = 100% 되돌림)을 넘으면 보내지 않고, 78.6%를 넘은 약한 자리는 본문에 경고를 붙입니다. 쿨다운은 `auto1:{종목}:{방향}` 키로 3중 점검과 따로 60분. 3중 점검 판정과는 별개인 참고 신호라 본문에도 그 사실을 적습니다.
- **예약주문 관점 감시** (2026-11-27 추가): 웹앱 `⏳ 예약주문`(지정가 대기)이 **구글 시트 `예약주문` 탭**에 동기화되고, `ntfy_alert.py`가 **미체결 주문이 있을 때만** 지정가에 닿기 전 관점이 바뀌는지 봅니다 — ① 무효화선(주문 SL·그 방향 가설 손절) 0.30% 이내 근접 / 돌파(1H 확정 종가로 '확정') ② 4H 종가가 EMA50 반대편 안착(구조 반전) ③ 반대편 가설 진입선(눌림 롱 / 숏 진입) 이탈(관점 식음) ④ 지정가 도달. 같은 주문·같은 사유는 180분 쿨다운, **미체결 0건이면 알림 없음**. 거래소 주문은 대신 내지 않습니다.
- 같은 판정을 피클 채팅으로도 받도록 `check.sh` 기반 예약 작업(`⏳ 예약주문 관점변경 감시`, 15분 간격)이 `scripts/order_watch.py`를 실행합니다. 알릴 사실이 없으면 실행을 열지 않아 피클 사용 한도를 쓰지 않습니다.
- 수동 실행: `python3 scripts/ntfy_alert.py --dry-run` (발송 없이 판정만) · `--test` (테스트 알림 1건) · `--json out.json`
- **자동 1 판정 카드** (웹앱, 2026-11-26 추가): «멀티 타임프레임 판정» 바로 아래에서 자동 1 후보를 같은 3중 점검(자리 ±1.0% · 라인 ±1.2% · 1H 다이버전스/확인봉)으로 실시간 판정합니다. 파동 무효·손절 이탈·1차 목표 경과는 무효/만료, 3/3이어도 구간 밖이면 대기, 현재가 기준 2차 손익비 3:1 미만이면 손익비 미달입니다. 카드를 누르면 그 값이 타점 계획으로 들어가고 아래로 이동합니다. 참고용이며 메인 판정·ntfy 알림·시트 기록에는 반영되지 않습니다.
- 가설을 새로 배포하면 `scripts/ntfy_alert.py`의 `HYP_DATA`(LEVELS·HYP·ZONE_DEF)를 같은 값으로 바꿔 커밋해야 알림 기준이 맞습니다.
